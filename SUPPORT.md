## Getting help

| Type | Where |
|---|---|
| Bug reports | [GitHub Issues](../../issues) (use the bug report template) |
| Feature ideas | [GitHub Issues](../../issues) (use the feature request template) |
| Questions & discussion | [GitHub Discussions](../../discussions) |
| Security issues | [SECURITY.md](SECURITY.md) — **private channel only** |

## Before opening an issue

1. Check that your question is not already answered in the README.
2. Search open and closed issues.
3. Include your OS, terminal, install method, and reproduction steps — issues
   without them cannot be triaged effectively.

## What to expect

IRIS is pre-release software. Response times vary; there is no SLA at this
stage. Critical security reports take priority over everything else.

**Never post credentials in public issues or discussions** — no API keys, no
`.env` contents, no tokens. Redact them before submitting.
